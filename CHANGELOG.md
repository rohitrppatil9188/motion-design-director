# Changelog

## 1.0.1 — 2026-10-30

- Rename the internal skill identifier and display title to `motion-design-director` / Motion Design Director, matching the repository.
- Update installation paths, invocation prompts and package validation. Existing users should rename their installed `kinetic-showreel-director` folder to `motion-design-director` and replace it with this release.
- Motion guidance, reference studies, recipes and rendering behavior are unchanged.

## 1.0.0 — 2026-10-29

Initial public release of Motion Design Director, with the skill identifier `kinetic-showreel-director`.

- 50 individually written Opus-attributed motion-film studies, source links and numerical evidence.
- 24 independent effect recipes and design, production, audio and quality-review guidance.
- Absolute-time animation and triangular-mesh helpers, licensed fonts, plan schema/validator, audio synthesis, rendering and media checks.
- Original OFFSET and independently authored FIELD NOTES projects, proof films and inspection sheets.
- Hardened loopback preview access, bounded media ranges, stricter numeric arguments and decoder error handling, and degenerate motion-parameter validation.
- Explicit Canvas text shaping and saved diagnostics for repeated-frame comparisons discovered during Linux browser CI.
- Public release documentation, contribution/security guidance, automated checks and canonical MIT licence with separate third-party notices.
